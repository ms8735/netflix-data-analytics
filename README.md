# 🎬 Netflix Data Analytics

## 📌 Project Overview

This project focuses on analyzing the Netflix content catalog to identify patterns and trends in movies and TV shows available on the platform.

The project uses **data analytics** to explore content distribution, genres, ratings, release years, countries, and other important characteristics of Netflix titles.



## 🎯 Objectives

The main objectives of this project are:

* Analyze the distribution of Movies and TV Shows on Netflix.
* Identify the most common content genres.
* Analyze Netflix content by release year.
* Examine content ratings and their distribution.
* Analyze the countries producing Netflix content.
* Identify trends in Netflix's content library.
* Extract meaningful insights from the dataset.

## 🧹 Data Preparation

The dataset was prepared before visualization.

The preprocessing steps included:

1. Handling missing values.
2. Removing duplicate records.
3. Converting date fields into appropriate formats.
4. Cleaning categorical values.
5. Splitting multi-value fields such as genres and countries where required.
6. Creating calculated fields for analysis.

## 🔍 Key Analysis Areas

### 1. Movies vs TV Shows

The project compares the number of Movies and TV Shows available in the dataset to understand the overall content composition.

### 2. Content Over the Years

The analysis examines how Netflix's content catalog has changed across different release years.

### 3. Genre Analysis

Popular genres and categories are analyzed to understand the types of content represented most frequently.

### 4. Rating Analysis

The distribution of content ratings is examined to understand the target audience represented in the Netflix catalog.

### 5. Country Analysis

The project analyzes content production across different countries and identifies countries with significant representation in the dataset.
